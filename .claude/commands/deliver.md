description: Record a delivery against a deal: a post, a ticket allocation, a signage install, a hospitality box.
---

Read CLAUDE.md. Run npm run sponsorship -- deliver <deal> --asset=<asset> [--quantity=1] [--event=<event>] [--on=YYYY-MM-DD] [--reach=N] [--evidence="where the photo or report lives"] --actor=<name>. Use --json when you need to work further with the rows. Never invent a record, a date, an amount or a delivery that is not in the records.

Ask where the evidence lives. A reach figure with no evidence is flagged by /compliance, because a proof of performance report must not claim what you cannot show. Confirm the record and values with the operator first. Every write needs --actor. Before update, sign, proof-sent or renew, read show and pass --expected-version. If a name matches more than one record, list them and ask which one.
