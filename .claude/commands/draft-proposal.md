Read CLAUDE.md. Run npm run sponsorship -- draft-proposal <partner>. Use --json when you need to work further with the rows. Never invent a record, a date, an amount or a delivery that is not in the records.

The draft goes to drafts/. Do not send it. A prohibited category gets no proposal; an adult-only category gets no junior assets; a category another partner holds exclusively is flagged.
