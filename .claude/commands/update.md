---
description: Update a record with a version check.
---

Read CLAUDE.md. Run npm run sponsorship -- update <entity> <record> --field=value --expected-version=N --actor=<name>. Use --json when you need to work further with the rows. Never invent a record, a date, an amount or a delivery that is not in the records.

Confirm the record and values with the operator first. Every write needs --actor. Before update, sign, proof-sent or renew, read show and pass --expected-version. If a name matches more than one record, list them and ask which one.
